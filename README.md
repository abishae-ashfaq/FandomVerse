# 🌌 FandomVerse — Explore. Discover. Celebrate.

FandomVerse is a fully responsive, single-page application (SPA) built for fans to explore their favorite universes — including Anime, Gaming, Movies, TV Shows, K-Pop, Comics, and Manga.

![FandomVerse Banner](https://images.unsplash.com/photo-1635863138275-d9b33299680b?w=1200&q=80)

## ✨ Features

- **Cinematic UI:** Dark, Netflix-inspired theme with GSAP-powered animations, particles, and smooth transitions.
- **7 Category Hubs:** Data-driven pages for Anime, Gaming, Movies, TV Shows, K-Pop, Comics, and Manga.
- **Detailed Views:** Dedicated pages for Articles, Characters, and Events.
- **Global Search:** Real-time dropdown search with a dedicated full results page.
- **Trailers:** Embedded YouTube modals with a dedicated Trailers page.
- **Merchandise & Cart:** Fully functional e-commerce simulation (Cart, Checkout, Order ID) using LocalStorage.
- **Bookmarks & Notes:** Save your favorite content, add private notes, and export them as a `.txt` file.
- **Rule-Based Chatbot:** Floating assistant panel that answers queries using a JSON-based keyword matcher.
- **Performance Optimized:** JSON caching, lazy-loaded images, and reduced particle counts for a smooth experience.

## 🛠️ Technology Stack

- **HTML5 & CSS3** (Custom Properties, Flexbox, Grid)
- **Vanilla JavaScript** (ES6+, Hash-based Routing, IntersectionObserver)
- **Bootstrap 5** (Responsive layout)
- **GSAP** (Animations)
- **LocalStorage & SessionStorage** (State management)
- **Fetch API** (Loading JSON data)
